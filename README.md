# Установка-необходимых-модулей
Для работы необходим podman-compose\
`sudo apt install podman-compose`
# Установка-веб-приложения
Просто клонируйте репозиторий\
`git clone https://github.com/ZogirderCMD/antispam_detector_restapi`
# Настройка-веб-приложения
В env файле установите параметры
| Название | За что отвечает |
| --- | --- |
| POSTGRES_DB | Имя базы данных |
| POSTGRES_USER | Имя пользователя базы данных |
| POSTGRES_PASSWORD | Пароль базы данных |
| POSTGRES_PORT | Порт базы данных |
| ADMIN_TOKEN | Токен администратора для просмотра логов |
| TZ | Зона времени |

Переименуйте env в .env\
`mv -i env .env`
# Запуск-веб-приложения
Перейдите в папку с docker-compose.yaml и выполните команду podman-compose\
`podman-compose up --build -d`
